# Changelog

All notable changes to the Elite Skills Library plugin will be documented in this file.

## [1.0.0] - 2026-01-19

### Added
- Initial release of Elite Skills Library plugin
- `/elite-skills:configure` command for API key setup
- `/elite-skills:status` command for subscription status
- Skills catalog with 270+ professional-grade skills
- API-authenticated skill delivery
- Free tier support (1 key, 100 requests/month)
- Professional tier support (5 keys, unlimited requests)
- Automatic skill caching with ETag validation
- Rate limit enforcement
- Comprehensive error handling

### Documentation
- Installation guide in README
- API key configuration instructions
- Usage examples
- Troubleshooting guide
